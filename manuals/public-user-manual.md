# QR Manager Public User Manual

## 1. Start The Institution Portal

Create or log into the institution portal, choose a plan, and confirm the free first month. Use the dashboard to check trust readiness, structure readiness, issuing readiness, and recent certificate activity.

## 2. Set Up Structure

Open Structure, choose the template that matches the institution, and confirm the change. The platform supports schools, colleges, training providers, professional bodies, companies, NGOs, churches, and custom structures.

## 3. Add Records

Open Records and add each student, learner, participant, employee, or member. Optional profile fields include a picture, headline, summary, skills, achievements, GitHub, LinkedIn, portfolio, website, project links, and internal notes.

## 4. Build Certificates

Use Certificate Builder to create reusable certificate templates. Edit text, colors, assets, badges, signatures, and QR or link placement. Save the template for later use.

## 5. Issue Certificates

Use QRIssuer to upload an existing PDF or select a reusable template. Place the QR code, save the record details, then export the finished certificate. In Builder, use Issue mode when the design is ready and you want to issue it directly to a selected record.

## 6. Verify Certificates

Every issued certificate receives a verification code. Public viewers can scan the QR code or open the verification link to confirm the recipient, institution, course, date, and issuer trust status.

## 7. Get Training And Setup Assistance

Use the Training and setup assistance link on the pricing section or Help page to request support with portal structure, templates, QRIssuer workflow, compliance readiness, and team handover.
